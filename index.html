About MiniMappr

MiniMappr is a browser build of PyMappr, a remake of SimpleMappr. It plots points from a CSV or manual entry onto a projected world map and exports PNG, JPEG, WebP, TIFF, PDF or SVG. Everything runs in the page; no data leaves the browser.

Not in this web version. Use desktop PyMappr for:

  • The ~30 Natural Earth vector layers (borders, states, cities, rivers, roads, time zones, and more)
  • Relief and Blue Marble raster basemaps, and bathymetry
  • City, place, and feature labels
  • Excel (.xlsx) import
  • Project files with autosave, and code export to Python (matplotlib) or R (ggplot2)

Built with D3, d3-geo-projection, and topojson-client (all ISC licence), plus a simplified world outline from world-atlas (derived from Natural Earth, public domain). Everything is inlined into this one HTML file.
